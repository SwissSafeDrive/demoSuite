# SwissSafeDrive

SwissSafeDrive es un proyecto tecnológico suizo B2G creado por David Induni y José Francisco Codino.

Su objetivo es desarrollar una plataforma de seguridad vial para policías municipales y cantonales, basada en cámaras, computer vision e inteligencia artificial, capaz de detectar eventos potencialmente compatibles con el uso del teléfono durante la conducción y presentarlos a personal policial autorizado para revisión humana.

## Principios

- La decisión sancionatoria es siempre humana.
- SwissSafeDrive no emite multas automáticamente.
- SwissSafeDrive no participa económicamente de las sanciones.
- Privacy by Design.
- Minimización de datos.
- Procesamiento local / edge cuando sea posible.
- Pseudonimización criptográfica cuando corresponda.
- Control de accesos, cifrado y trazabilidad.
- Preferencia por soberanía de datos y deployment on-premise.
- Validación jurídica antes de cualquier piloto en vía pública.
