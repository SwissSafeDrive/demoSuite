SWISS SAFE DRIVE
AI Demo Suite — Agire Foundation Pitch

Making roads safer through artificial intelligence

A suite of AI-powered tools for real-time driver monitoring, hazard detection, and autonomous driving model training. Built to demonstrate how AI can meaningfully reduce road incidents.

DEMO 01
Camera AI Analyzer
Real-time detection of distracted drivers using standard security camera footage. No specialized hardware required.
  • Cell phone detection via COCO-SSD
  • Driver–phone proximity analysis
  • Live alert system with event log
  • Runs entirely in browser (TensorFlow.js)
Live Demo
DEMO 02
Eye Concentration Monitor
Detects driver drowsiness and distraction by tracking gaze direction and eye closure duration in real time.
  • MediaPipe FaceLandmarker · 478 landmarks
  • Blendshape-based gaze state analysis
  • Drowsiness timer with escalating alerts
  • Gaze compass direction indicator
Live Demo
DEMO 03
In-Car Hazard Alert System
Dashcam-style AI that detects pedestrians, vehicles and cyclists and scores collision risk in real time.
  • COCO-SSD object detection · 80 classes
  • Proximity scoring by bounding box height
  • Hazard level gauge (clear → danger)
  • Simulated speed readout · audio alerts
Live Demo
DEMO 04
AI Training Data Collector
Simulates a vehicle-mounted data collection device — auto-labeling scenes and streaming to a training dataset pipeline.
  • COCO-SSD auto-labeling with annotation IDs
  • Simulated GPS (Zurich) + IMU sensor fusion
  • Dataset quality scoring per frame
  • Batch sync to cloud every 100 frames
